# Changelog

## 0.1.0 (unreleased)

First version.

- Checks text you **paste or drop**, and files you **attach**, on 45 AI chat and AI app-builder sites (ChatGPT, Claude, Gemini, Copilot, Perplexity, Grok, DeepSeek, v0, Bolt, Lovable, Replit and more), and on any other https site you add with **Protect this site** in the toolbar popup (the browser asks for that one site). Ordinary text is never touched.
- **Holds a send that still contains a secret.** Pressing Enter or the site's Send button with a secret in the box is stopped and a dialog asks: Redact the message, Keep it and let me send, or Cancel. Paste Guard never sends a message itself; you press send again. Shift+Enter and IME composition are left alone, and it can be switched off in Settings.
- **Reads inside Word, Excel, PowerPoint, OpenDocument and zip files** when you attach them (text parts only, size-limited so a zip bomb cannot expand, nothing is uploaded).
- **Finds provider keys that were hard-wrapped across lines**, without swallowing the words that follow them.
- 121 detection rules (102 provider key formats), the newer ones written from each provider's published key format with public scanner rule sets (gitleaks, MIT licensed) used as a reference for those formats. Included are credentials in URL query strings (`?api_key=...`), short names like `DB_PASS` and `SESSION_KEY`, command-line passwords (`curl -u`, `docker login -p`, `mysql -p`, `sshpass`, `redis-cli -a`), `.netrc` entries, and private keys written with `\n` escapes (Google service-account JSON). Zero-width characters inside a token no longer hide it: provider API keys, private keys, JWT / Bearer / Basic tokens, passwords and secrets in code and URLs, card numbers (Luhn), IBANs, US SSN, Indian Aadhaar (Verhoeff) and PAN. Emails, phone numbers and random-looking strings are available but off by default.
- Built to stay quiet: placeholders, documentation examples, public test card numbers, code references like `process.env.KEY`, and metadata like `token_type` are ignored.
- A warning dialog (closed Shadow DOM, light and dark, keyboard and screen-reader friendly) with **Redact and paste**, **Paste anyway** and **Cancel**, a masked preview of every finding, a preview of the redacted text, and a per-value "this is fine".
- **Warns while you type**: if a secret appears in the message box without a paste (typed, dictated, autofilled), a non-blocking banner with a one-click Redact appears. It takes no focus, ignores password fields and IME composition, goes away when the box is cleared, and does not re-flag values you dismissed or chose to paste anyway. Switch it off in Settings.
- The masked preview of a private key written on **one line** (Google service-account JSON) showed the whole key; it now shows only the `-----BEGIN ... PRIVATE KEY-----` header and a length. A test now checks every rule's preview against its own samples, so no kind of secret can be displayed in full.
- The typing warning's **Redact** replaces the box's contents reliably in rich editors such as ChatGPT's. Rich editors learn about a new selection a moment late, so selecting everything and inserting at once appended a second copy and left the secret in place. Redact now waits for the editor, empties the box with the browser's own delete, inserts, and then checks that the secret is really gone, trying other methods and finally telling you if it cannot.
- Works in plain inputs, `contenteditable` boxes and rich editors that handle paste themselves, without inserting text twice.
- Settings: three sensitivity levels, ask / redact automatically / block, per-category switches, file scanning, custom patterns (with a guard against patterns that could freeze the page), per-site pause, a live "Try it" playground, counters, and settings export and import.
- Chrome, Edge, Brave and Firefox builds from one source. No dependencies and no build step.
- Privacy by construction: no network code, no `eval`, no `innerHTML`, minimal permissions, all enforced by tests.
